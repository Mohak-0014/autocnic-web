# autocnic-demo-pricing

A checkout-pricing pipeline for the AutoCNIC web demo. Two dependencies are
genuinely conditional in the code but never declared as such -- the app
discovers them itself via controlled perturbation experiments + predicate
mining. See `autocnic_pipeline.py`.

Push this repo to your own GitHub account, then paste its clone URL
(`https://github.com/<you>/autocnic-demo-pricing.git`) into the AutoCNIC web
app.
