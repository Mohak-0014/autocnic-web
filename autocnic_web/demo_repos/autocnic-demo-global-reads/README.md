# autocnic-demo-global-reads

An inventory-pricing pipeline for the AutoCNIC web demo, built to exercise
static (beniget) discovery of dependencies that are read as module-level
globals rather than function parameters. See `autocnic_pipeline.py`.

Push this repo to your own GitHub account, then paste its clone URL
(`https://github.com/<you>/autocnic-demo-global-reads.git`) into the AutoCNIC
web app.
