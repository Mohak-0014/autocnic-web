Every skipped computation comes with a proof

Recompute only what a change can actually affect.

Point AutoCNIC at a project. It discovers which dependencies are conditional, then issues an independently verified certificate for every value it safely skips when an input changes.

Cloning, importing the pipeline and running perturbation experiments — a few seconds…
The project needs an autocnic_pipeline.py at its root exposing PIPELINE and SAMPLERS.

Why teams use it

Stop re-running expensive steps that a change can't touch — and be able to prove it.

Discovers conditional dependencies

Controlled perturbation experiments reveal which edges only matter under a condition, and mine the predicate that gates each one.

Recomputes only what's affected

An input change re-runs just the nodes reachable through active edges. Everything else keeps its value.

Certificates you can verify

Every skipped node gets a certificate that a separate checker validates without rerunning any analysis. All are saved to disk.
